stack	import() nested in an expression (id(import('x')), a && import('x'), (await import('x')), [1, import('x')]) reports the position V8 emitted last (statement start, operator, array literal); jsse reports the import keyword
stack	import(a + b) and import(`${x}`) report the operator and template positions in V8; jsse reports the import keyword / await
