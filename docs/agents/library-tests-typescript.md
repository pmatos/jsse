# Library Tests: TypeScript oracles

Split from [library-tests.md](library-tests.md) to keep each file under the 20,000-byte budget.

- **`tsc` oracle**: `TSC_DIR=<typescript 6.0.3 package> ./scripts/run-tsc-oracle.sh [--full] [--no-timing]` diffs `lib/_tsc.js` (`--version`, `--help`, `--all`, `--init`, `--noLib` compiles, `bin/tsc`) on jsse `--node` and Node and checks startup under 1 s (skips without `TSC_DIR`). Guards: `tests/node_tsc.rs`; design: `docs/adr/2026-10-27-0100-node-host-tsc-startup.md`.
- **`tsc --watch` oracle**: `TSC_DIR=<typescript 6.0.3 package> uv run python scripts/run-tsc-watch-oracle.py [--jobs N] [--ci] [--dump DIR] [case ...]` drives the 38 scripted edit/create/delete/rename/config sessions of `scripts/tsc-fixtures/watch-cases.txt` (every watch strategy, `--preserveWatchOutput`, `--excludeDirectories`, `-b -w`) through `tsc -w` on jsse `--node` and Node and diffs the recorded diagnostics sequence, emitted files and exit status per step (skips without `TSC_DIR`; `--pin`/`--no-node` use `watch-expected.txt`). Guards: `tests/node_tsc_watch.rs`, `scripts/test_run_tsc_watch_oracle.py`; design: `docs/adr/2026-10-27-1756-node-host-tsc-watch.md`.
- **`tsc` project oracle**: `TSC_DIR=<typescript 6.0.3 package> uv run python scripts/run-tsc-projects-oracle.py [--jobs N] [--ci] [case ...]` compiles the 23 cases of `scripts/tsc-fixtures/cases.txt` (`--noEmit`, emit, `--declaration`, error projects, tsconfig projects, `--build`) on jsse `--node` and Node and diffs stdout, stderr, exit code and every emitted file (exit 1 on any diff; skips without `TSC_DIR`). Guards: `tests/node_tsc_projects.rs`, `scripts/test_run_tsc_projects_oracle.py`; design: `docs/adr/2026-10-27-0900-node-host-tsc-projects.md`. `scripts/tsc-fixtures/cases-build.txt` adds the `--build`/`--incremental` scenarios (touch and rerun steps; `docs/adr/2026-10-27-1500-node-host-tsc-build.md`).
- **`tsc` diagnostics oracle**: the `diag-*` cases of `scripts/tsc-fixtures/cases-diagnostics.txt` (30+ error fixtures plain and `--pretty`, auto/`NO_COLOR`/`FORCE_COLOR` on pipes and ptys, `--help` widths, `--noErrorTruncation`, every `--locale`, exit codes) run by the same script; design: `docs/adr/2026-10-27-1000-node-host-tsc-diagnostics.md`.
- **`tsc` informational-flags oracle**: the `info-*` cases of `scripts/tsc-fixtures/cases-info.txt` (`--listFiles`, `--explainFiles`, `--showConfig`, `--init`, `--traceResolution`, `--diagnostics`, `--extendedDiagnostics`, `--generateTrace`, `--generateCpuProfile`) run by the same script; design: `docs/adr/2026-10-27-1100-node-host-tsc-info.md`.
- **`tsc` emit matrix**: the `emit-*` cases (193 option combinations over `projects/emit`: target x module, moduleResolution, source and declaration maps, `--outFile`, `--importHelpers`, JSX modes, decorators, `.mts`/`.cts`, `allowJs`/`checkJs`) are generated by `scripts/gen-tsc-emit-cases.py` into `scripts/tsc-fixtures/cases-emit-*.txt` and run by the same script; design: `docs/adr/2026-10-27-1100-node-host-tsc-emit-matrix.md`.
- **TypeScript suite oracle**: `uv run python scripts/run-ts-suite-oracle.py` fetches the pinned TypeScript v6.0.3 tree into a cache outside the repo, builds it and runs every runner on Node, checking counts and digests against `ts-suite/oracle.json` (`ts-suite/README.md`; design: `docs/adr/2026-10-27-1000-node-host-ts-suite-pin.md`).
- **hereby oracle**: `TS_SRC_DIR=<TypeScript v6.0.3 checkout, npm ci done> uv run python scripts/run-hereby-oracle.py [--jsse BIN] [case ...]` runs the hereby CLI (TypeScript Herebyfile and `scripts/hereby-fixtures`: task graphs, failing tasks, load errors, colour, pty) plus chokidar/glob/picocolors/canceltoken on Node and `jsse --node` and diffs them (skips without `TS_SRC_DIR`). Guards: `tests/node_hereby_deps.rs`, `scripts/test_run_hereby_oracle.py`; design: `docs/adr/2026-10-27-1100-node-host-hereby.md`.
- **`hereby local` oracle**: `TS_SRC_DIR=<TypeScript v6.0.3 checkout, npm ci done> uv run python scripts/run-hereby-local-oracle.py [--jsse BIN] [--skip-harness]` copies the checkout twice, runs `hereby local` (diagnostics generation, `tsc -b` of `src/` by `node_modules/typescript`, esbuild bundles of `tsc`, `typescript`, `tsserver`, the d.ts bundles) on Node and `jsse --node`, diffs the logs and every file under `built/` (the d.ts bundles included, #1378) plus the generated sources, then runs the tsc project oracle on the jsse-built compiler (skips without `TS_SRC_DIR`). Guards: `tests/node_hereby_local.rs`, `scripts/test_run_hereby_local_oracle.py`; design: `docs/adr/2026-10-27-1600-node-host-hereby-local.md`.
- **WebAssembly oracle**: `./scripts/run-node-wasm-oracle.sh [--node] [--no-cross-check]` runs `scripts/wasm-fixtures/{api,run}.js` (modules encoded in JS by `builder.js`) on jsse `--node` and Node and diffs stdout: API shape and attributes, calls and coercion, traps, linear-memory aliasing and detach-on-grow, imports and re-entrancy, tables, globals, start, multi-value, promises. Guards: `tests/node_wasm.rs` (plain, `--no-bytecode`, `JSSE_GC_STRESS=3`); design: `docs/adr/2026-10-28-1200-node-host-webassembly.md`. The d.ts bundles of `hereby local` (dprint's plugin) are its real-world check.
- **esbuild oracle**: `ESBUILD_DIR=<esbuild 0.27.3 package> [TS_SRC_DIR=<TypeScript checkout>] ./scripts/run-node-esbuild-oracle.sh` runs the esbuild JS API and its native service child, including the TypeScript bundle, on jsse `--node` and Node and diffs stdout and exit status (skips without `ESBUILD_DIR`). Guards: `tests/node_esbuild.rs`; design: `docs/adr/2026-10-27-1000-node-host-esbuild.md`.
- **TypeScript unit-test oracles** (top-level, services, evaluation, tsbuild, config/sys, `tsc` CLI, watch): see [Library Tests: TypeScript unit tests](library-tests-typescript-unittests.md).
- **mocha / TypeScript unit-test oracle**: `TS_SRC_DIR=<built TypeScript v6.0.3 checkout> uv run python scripts/run-ts-mocha-oracle.py [--jobs N] [case-glob ... '!glob' ...]` runs mocha 10's CLI (`_mocha`, the way `hereby runtests` does) on `scripts/ts-mocha-fixtures` and the TypeScript runner `built/local/run.js` (a `test.config` selects one unit-test suite) on jsse `--node` and Node, and diffs stdout, stderr, exit status and `.failed-tests`/`TEST-results.xml`/`report.xml`/`report.json` (skips without `TS_SRC_DIR`; never writes into the checkout). The 109 mocha cases (table in `scripts/ts_mocha_cases.py`) cover all thirteen non-browser reporters on passing and failing suites, `timers-*` (timer queue order, `refresh`, intervals, `timers/promises`, mocha's own `duration` against the sleep), `timeouts-*` and `cli-timeout-*` (test and hook limits, `-t 0/60/1s`, raised/lowered mid-test, sync overrun, `--slow` speed classes), `diff-*` (assertion and `actual`/`expected` diffs, `--no-diff`, `--inline-diffs`, `--colors`), `retries-*`, `--bail`, `-g/-f/-i`, `--forbid-only/-pending`, `--check-leaks`, `--dry-run`, `--delay`, `-u tdd`, `--full-trace`, `--list-reporters`, and `--reporter-option output=`. Guards: `tests/node_ts_mocha.rs` (strict tail calls are ordinary calls under `--node`), `tests/node_exit_in_callbacks.rs` (`process.exit` inside builtin callbacks), `scripts/test_run_ts_mocha_oracle.py`; design: `docs/adr/2026-10-27-1600-node-host-mocha.md`. The `cli-*` cases (`scripts/ts_runner_cli_cases.py`, fixture `runtests.mjs`) run `scripts/build/tests.mjs`'s `runConsoleTests`, i.e. what `hereby runtests` does after its build tasks, with `--runner`/`--ru`, `--tests`/`-t`, `--shards`/`--shardId`, `--light`/`--no-light`, `--failed`, `--keepFailed`, `--colors`/`--no-color`, `--timeout`, `--skipSysTests`, `--stackTraceLimit`: `cli-list-*`, `cli-tests-*` and `cli-shards-*` print every registered test title (mocha `--dry-run`) and must match Node line for line (the shards of conformance, project and fourslash must add up to the runner's whole list), `cli-run-*` execute a few real baseline tests per runner, `cli-failed-*` re-consume `.failed-tests` in a second step, and `cli-baseline-accept` runs `hereby baseline-accept` on a private baseline tree. The `par-*` cases (`scripts/ts_runner_parallel_cases.py`, fixture `par-crash.js`) run `hereby runtests-parallel`'s host (`runConsoleTests(..., true)`, `TS_PARALLEL=1`, `--workers`/`-w`): `par-run-*` against `par-serial-*` on the same sample (counts must agree), `par-workers-8`, and `par-crash-*` (a worker that exits, is killed, throws or rejects ends the run with status 2 and a report, no hang). Every case runs in its own session via `scripts/oracle_procs.py`; the whole process group is killed (SIGTERM, then SIGKILL) when the case ends, times out, or the oracle gets SIGINT/SIGTERM/SIGHUP, and `par-crash.js` workers exit on `disconnect`, so forked workers are never orphaned. The full lists of conformance, compiler and unittest take minutes on jsse (`--timeout` defaults to 1800 s). The `eslint-*` cases (`scripts/ts_eslint_cases.py`, fixtures `scripts/ts-eslint-fixtures`) run `hereby run-eslint-rules-tests` itself (TypeScript's custom ESLint rules through typescript-eslint's RuleTester, 79 tests) with the checkout's Herebyfile in a work directory: every reporter, `--tests` filters, extra passing rule tests, and a fixture failing every way RuleTester reports with the `--failed` re-run (`docs/adr/2026-10-28-1400-node-host-eslint-rules.md`; guard `tests/node_worker_threads.rs`).
- **`tsc` self-compile oracle**: `TS_SRC_DIR=<TypeScript v6.0.3 checkout, npm ci done> [TSC_DIR=<typescript 6.0.3 package>] uv run python scripts/run-tsc-selfcompile-oracle.py [--smoke] [--jobs N] [--report FILE] [case ...]` compiles TypeScript's own `src/` with tsc 6.0.3 on Node and `jsse --node` (cases `compiler-dts`, `compiler-js`, `src-js`, `generated-large`), diffs every emitted file byte for byte, and prints wall time and peak RSS per engine; the budget in `scripts/tsc-fixtures/selfcompile-budget.json` caps jsse peak RSS at 6x Node per case (`max_rss_ratio`); wall time is recorded, not enforced (`--max-seconds`/`--max-rss-mb` override per run). `--smoke` needs only `TSC_DIR`; skips without the inputs unless `--require`. CI: `tsc-selfcompile-smoke.yml` (`--smoke`, non-required, on PRs/pushes touching the engine or the oracle) and `nightly-tsc-selfcompile.yml` (all cases, non-blocking, report artifact). Guards: `tests/node_tsc_selfcompile.rs` (`--smoke`), `scripts/test_run_tsc_selfcompile_oracle.py`; design and measurements: `docs/adr/2026-10-27-1900-node-host-tsc-selfcompile.md`.
- **TypeScript unit tests: tsserver** (#1266 files a-m, #1267 files n-z): `TS_SRC_DIR=<built TypeScript v6.0.3 checkout> uv run python scripts/run-ts-unittests-tsserver-oracle.py [--half a-m|n-z|all] [--jobs N (at most 4)] [--verbose] [--record] [group ...]` is the #1260 oracle (same options and per-title comparison) over `scripts/ts_unittest_tsserver_groups.py`. The table lists every file of `src/testRunner/unittests/tsserver` (80 files, 1240 tests, the `tsserver` suite of `ts-suite/oracle.json`) with the title prefix of its describes (not always the file name: `projectReferences.ts` is `with projectReferences::`), assigns each to a half by the first letter of its name (`events/*` is `e`) and packs the files of a half into groups, one jsse process per group (27 groups: 15 for a-m, 12 for n-z). `--half` (default `a-m`) picks what a bare run executes; naming groups runs them whatever their half. The baseline `ts-suite/unittests-tsserver.json` holds the counts of all 27 groups and `known_failures` (empty); the pinned 1240 is checked on bare runs against this run plus the baseline counts of the groups left out. A run with `TS_SRC_DIR` first checks the table against the checkout (a file or top-level `describe` no group selects, or two groups select, fails it). All 421 tests of a-m take about 3 minutes at 4 jobs and all 819 of n-z (projectReferencesSourcemap alone is 273) about 9 minutes, and all 1240 pass on both engines in full mode; a jsse process takes 45 to 300 s, mostly loading the runner bundle (per-test mocha timeout 600 s). Guards: `tests/node_ts_unittests_tsserver.rs` (a-m and n-z cases), `scripts/test_run_ts_unittests_tsserver_oracle.py`.
- **TypeScript `compiler` runner** (#1268): `TS_SRC_DIR=<built TypeScript v6.0.3 checkout> uv run python scripts/run-ts-compiler-oracle.py [slice ...]` runs slices of `tests/cases/compiler` (default the first 200 suites) on Node and `jsse --node`, diffing outcomes, error messages and every local baseline file, with a corrupted-reference control and a known-failure ratchet; see [library-tests-typescript-compiler.md](library-tests-typescript-compiler.md).
