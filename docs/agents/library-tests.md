# Library Tests (Node-compat harness)
Real-world npm libraries are run as engine stress tests via a generalized
harness. See `scripts/README.md` for the full recipe and how to add a library.
- Run one library: `./scripts/run-library-tests.sh <lib>` (e.g. `decimal.js`, `big.js`, `acorn`).
- Run on Node only (reference oracle): `./scripts/run-library-tests.sh <lib> --node`.
- Force a fresh clone/rebuild: `./scripts/run-library-tests.sh <lib> --clean`.
- Each library has a config at `scripts/libs/<lib>.sh` (pinned repo/ref, bundle entry, prepare hook, verdict). The runner clones the pinned ref, bundles with a pinned esbuild, runs it with `jsse --node`, which evaluates the Node prelude embedded in the binary (`scripts/node-shim.js` for `process`/`console`/`util`, `node-process-shim.js` for real `process.argv`/`env`/`cwd`/`exitCode`/`exit`, `node-buffer-shim.js` for `Buffer`/`TextEncoder`/`TextDecoder`, `node-crypto-shim.js` for `crypto.getRandomValues`, `node-event-loop-shim.js` and `node-timers-shim.js` for `nextTick`, timers, immediates and the `process` lifecycle events) — nothing is prepended and the prelude is never evaluated without `--node`, so test262 is unaffected — and cross-checks the test count against Node. Only a library's own `LIB_SHIM`/`LIB_SHIMS` are still prepended. Caches live under `/tmp/jsse-libtests/<lib>/`.
- The shim stubs are guarded so they are inert on Node, letting `--node` run the identical bundle as the reference.
- **`Buffer`** is a pure-JS subclass of `Uint8Array` (`node-buffer-shim.js` in the embedded prelude), needing zero new engine object kinds; `instanceof Uint8Array` holds. Self-verifying fixtures live in `scripts/shim-fixtures/`; run them (jsse + Node cross-checked) with `./scripts/run-shim-fixtures.sh`.
- **Currently green (cross-checked vs Node):** `decimal.js` (22,624), `big.js` (47,456; ~7 min — heavy arbitrary-precision arithmetic on the tree-walker), `acorn` (13,507), `prismjs` (2,563), `uglify-js` (4,233; ~15 min — full compress DSL transform/mangle/codegen corpus), `highlight.js` (731; ~30 min for the full auto-detection competition set), `uuid` (75; pinned to the browser build so v3/v5 exercise its own pure-JS MD5/SHA-1 and v1/v4/v6/v7 draw randomness from a `crypto.getRandomValues` shim backed by `__host_random_bytes` — see the prelude's `node-crypto-shim.js`).
- **`bignumber.js`** is wired but blocked on a jsse bug it surfaced (strict-mode `return <call-returning-non-object>` in a constructor returns that value instead of `this`, jsse#238); it goes green once that engine bug is fixed.
- **`luxon`** is wired at 3.7.2 with an exact 1,152-test Node cross-check. Node itself fails 13/1,152 on this host (ICU/Node version drift, not a jsse bug); jsse currently passes 1,002, with the remaining Intl/system-zone gaps tracked in jsse#262–#265.
- **`zod`** is wired at v4.4.3 in separate normal and jitless processes with an exact 2,184-case Node cross-check. Node is green; jsse runs every case with no skips and reports 2,178 passing, with the 6 residual failures tracked in jsse#313 (1 per mode) and jsse#314 (2 per mode). jsse#310's artificial `500 → 0` refinement-delay patch in `gen-zod-entry.js` is still in place.
- **`moment`** is wired at 2.30.1 with an exact 3,871-test Node cross-check. Node is green with 162,868 assertions; jsse executes every test and records 198 visible failing assertions, tracked in jsse#311.

### Acorn (`./scripts/run-acorn-tests.sh` — thin wrapper over the harness)
- Pinned to **acorn 8.16.0** (13,507 tests, green on jsse and Node). 8.17.0+ added a parser stack-guard test (`"[".repeat(2000)`) that expects the engine to *throw* a "stack space" error; jsse's tree-walker aborts (SIGABRT) before acorn's guard fires — a jsse deep-recursion robustness gap tracked separately. Bump the pin once that lands.
- **esbuild comment stripping**: esbuild removes comments from function bodies. The `TestComments` test relies on `Function.prototype.toString()` preserving comments, so a pre-bundle patch (`scripts/patch-acorn-comments.js`) replaces the `.toString()` call with a string literal.
- **Prelude oracle**: `./scripts/run-node-prelude-oracle.sh` runs `scripts/prelude-fixtures/*.fixture.js` as bare scripts on jsse `--node` and Node (nothing prepended) and diffs stdout and stderr, then checks the prelude is absent without `--node` (plain and `--prelude`). Rust-side guards: `tests/node_prelude.rs`.
- **`process` oracle**: `./scripts/run-node-process-oracle.sh` runs `scripts/process-fixtures/*.fixture.js` on jsse `--node` and Node and diffs stdout and exit status (argv, env, cwd/chdir, exitCode). Design: `docs/adr/2026-10-26-0854-node-host-mode.md`.
- **`path` oracle**: `./scripts/run-node-path-oracle.sh` runs Node's own `test-path-*.js` (verbatim, in `scripts/path-fixtures/`) and a ~41k-call differential corpus on jsse `--node` and Node, diffs the corpus output byte for byte, and checks its digest against `scripts/path-fixtures/corpus.digest`. Rust-side guards: `tests/node_path.rs`. The module is `node-lib/path.js` and friends; see the embedded builtin modules addendum in the ADR.
- **CommonJS oracle**: `./scripts/run-node-cjs-oracle.sh` runs the fixture project `scripts/cjs-fixtures/proj/main.js` (and `eval.js` via `-e`) on jsse `--node` and Node and diffs the normalised output, which is also pinned in `scripts/cjs-fixtures/expected-{main,eval}.txt` (`--node` regenerates them from Node). Under `--node` a script file is the CommonJS main module; see `docs/adr/2026-10-26-1400-node-cjs-loader.md`.
- **`fs` oracle**: `./scripts/run-node-fs-oracle.sh` runs `scripts/fs-fixtures/*.fixture.js` on jsse `--node` and Node against an identically seeded fixture tree (`FS_ORACLE_DIR`, with symlinks) and diffs stdout and stderr (file and descriptor I/O, stat, directories, links, argument and errno errors; the #1218 fixtures `stats`/`dirs`/`ops`/`cp`/`errnos` cover Stats, readdir, mkdir -p, rm, cp and an errno matrix against Node v26.8.2), then checks the floor is absent without `--node`. Rust-side guards: `tests/node_fs.rs` (including a 128 MiB no-extra-copy check). Design: `docs/adr/2026-10-26-0854-node-host-mode.md`.
- **Event-loop oracle**: `./scripts/run-node-event-loop-oracle.sh` runs `scripts/event-loop-fixtures/*.fixture.js` (header `// RUN: <status>`, optional `// ERR: <stderr substring>`) on jsse `--node` and Node and diffs stdout and exit status (nextTick/microtask/timer/immediate ordering, ref/unref, beforeExit/exit, uncaught exceptions, unhandled rejections, `timers`), then checks the surface is absent without `--node`. Keep fixtures to orderings Node makes deterministic (never `setTimeout(0)` against `setImmediate` from the main script) and run each on Node ~20 times before trusting it. Rust-side guards, including the default-loop pins: `tests/node_event_loop.rs`.
- **`events` oracle**: `./scripts/run-node-events-oracle.sh` runs 30 of Node's own `test/parallel` event, EventTarget and AbortController tests (verbatim, in `scripts/events-fixtures/`, listed in `manifest.txt`) and a differential corpus (events, `once`/`on`, `captureRejections`, EventTarget, `AbortSignal.any/timeout`, DOMException) on jsse `--node` and Node, diffs the corpus stdout byte for byte, and checks its digest against `scripts/events-fixtures/corpus.digest`. Tests marked `needs-process-events` / `needs-inspect` run once `process.on/emit` work / `util.inspect` names classes. Rust-side guards: `tests/node_events.rs`. See the events addendum in the ADR.
- **`url` oracle**: `./scripts/run-node-url-oracle.sh` runs the ~29k-line differential corpus in `scripts/url-fixtures/` (WHATWG `URL`/`URLSearchParams`, every setter, legacy `url.parse/format/resolve`, file URL conversion on posix and win32, IDNA, `querystring`, `punycode`) on jsse `--node` and Node, diffs it byte for byte, and checks its digest against `scripts/url-fixtures/corpus.digest`. Rust-side guards: `tests/node_url.rs`. The WHATWG parser is `node-lib/internal/url/parser.js` and friends; IDNA is the `__host_idna_*` floor over the `idna` crate (ADR addendum for #1230).
- **`os` oracle**: `./scripts/run-node-os-oracle.sh` runs `scripts/os-fixtures/probe.js` on jsse `--node` and Node under ten environments (HOME/TMPDIR variants, in-script `process.env` edits) and diffs stdout byte for byte: deterministic values, module shape, constants with descriptors, and the structure of freemem/uptime/loadavg/cpus. Rust-side guards: `tests/node_os.rs` and the unit tests in `src/interpreter/builtins/node_host_os*.rs`. The module is `node-lib/os.js` over the private `__host_os` binding.
- **`buffer`/`string_decoder` oracle**: `./scripts/run-node-buffer-oracle.sh` diffs `scripts/buffer-fixtures/{sd,buffer}-probe.js` (every StringDecoder encoding cut at every point, transcode matrix, isUtf8, Blob/File) between jsse `--node` and Node and checks the pinned digests. Rust-side guards: `tests/node_buffer.rs`.
- **`util` oracle**: `./scripts/run-node-util-oracle.sh` diffs the `scripts/util-fixtures/` corpus (inspect under every option, format, `util.types`, promisify, parseArgs, ...) on jsse `--node` and Node and checks its digest. Guards: `tests/node_util.rs`; design: `docs/adr/2026-10-26-1900-node-host-util.md`.
- **ESM oracle**: `./scripts/run-node-esm-oracle.sh` diffs `scripts/esm-fixtures/proj/main.mjs` (static and dynamic `import`, packages, JSON, builtins, TLA) on jsse `--node` and Node; guards: `tests/node_esm.rs`; design: `docs/adr/2026-10-26-1700-node-esm-loader.md`.
- **`crypto` oracle**: `./scripts/run-node-crypto-oracle.sh` diffs `scripts/crypto-fixtures/{hashes,random}.js` (digests, streaming, large inputs, HMAC, encodings, errors, random shapes, `subtle.digest`) on jsse `--node` and Node. Rust-side guards: `tests/node_crypto.rs`. See `docs/adr/2026-10-26-1930-node-host-crypto.md`.
- **`stream` oracle**: `./scripts/run-node-stream-oracle.sh` runs Node's own `test-stream*.js` (185 verbatim, in `scripts/stream-fixtures/`, `!` lines in `manifest.txt` explain the rest) and a differential corpus on jsse `--node` and Node. Guards: `tests/node_stream.rs`; design: `docs/adr/2026-10-26-2000-node-host-stream.md`.
