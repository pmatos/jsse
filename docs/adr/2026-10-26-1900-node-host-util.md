# Node host mode: the full `util` module and Node's `util.inspect`

Status: accepted, epic #1214, issue #1224. Ported from Node v26.8.2
(`lib/util.js`, `lib/internal/util/{inspect,types,comparisons,debuglog,colors,
parse_args/*,diff}.js`, `lib/internal/{mime,assert}.js`, parts of
`lib/internal/{util,errors,validators}.js`). Builds on the embedded builtin
table of `2026-10-26-0854-node-host-mode.md`.

## Decision

1. **Vendored, not rewritten.** The module is Node's own source in
   `node-lib/`, reached as the builtin id `util` (`__node_builtin("util")`)
   until the CommonJS loader (#1219) adds `require`. The prelude's `util` global
   (`scripts/node-shim.js`) is untouched and stays what library harnesses and the
   no-host fallback use; it is replaced when #1219 lands.
2. **`inspect.js` is nine files.** The upstream file is 102 KB and the budget is
   20,000 bytes per file. `internal/util/inspect.js` is the facade (options,
   `inspect`, colours and styles); `inspect_text` (escaping, width, numbers,
   primitives), `inspect_highlight` (RegExp colouring), `inspect_error`,
   `inspect_collections` (arrays, typed arrays, Map/Set, iterators, promises),
   `inspect_raw` (`formatRaw` and the class/function/boxed bases),
   `inspect_value` (`formatValue`, constructor names, keys),
   `inspect_property` (properties, line breaking) and `inspect_format`
   (`format`, `formatWithOptions`) hold the functions in their upstream bodies.
   The functions are mutually recursive, so no part requires another: each
   declares the foreign functions it calls as `let` variables and exports
   `init(deps)`; the facade requires every part and wires them once at load. A
   part never runs a foreign function at load time. `comparisons.js` is split the
   same way (`comparisons_sets` for the Set/Map/array equivalences), and
   `util.js` moves `styleText` to `internal/util/style_text`.
3. **`internalBinding` is two JS modules over a small native floor.**
   `node-lib/internal/binding/{util,types}.js` replace V8's
   `internalBinding('util')` and `('types')`. The floor
   (`src/interpreter/builtins/node_host_util.rs`) adds six trap-free, read-only
   primitives, captured by the builtin loader at prelude time and then deleted
   from the global object like the other floor globals:
   `__host_util_kind` (the internal-slot brand: Map, Set, WeakMap, WeakSet,
   Promise, Proxy, Date, RegExp, Error, Arguments, generator object, Map/Set
   iterator, ArrayBuffer, SharedArrayBuffer, DataView, ModuleNamespace, boxed
   primitives, async/generator function kinds), `__host_util_promise_details`,
   `__host_util_proxy_details` (target and handler; the older
   `__host_proxy_target` that the shim depends on is unchanged),
   `__host_util_preview_entries` (Map/Set iterators and weak collections without
   consuming them), `__host_util_own_non_index` (own keys without visiting index
   properties, so inspecting a million-element Array stays bounded by
   `maxArrayLength`) and `__host_util_class_name` (the stand-in for
   `GetConstructorName`). `util.types.*` is these brands plus the typed-array
   `@@toStringTag` getter, so every predicate agrees with Node on the corpus.
4. **Loader additions.** The primordials table gains the names the vendored code
   needs (`TypedArray*`, `AggregateError*`, `SafeMap/Set/WeakMap/WeakSet/WeakRef`,
   `SafeStringIterator/ArrayIterator`, `uncurryThis`, `globalThis`,
   `ArrayPrototypePushApply/UnshiftApply`, `SafeStringPrototypeSearch`, and a
   no-op `ErrorCaptureStackTrace` where the engine has none). The old
   `internal/util/inspect` stub in the loader, which returned the shim's inspect
   to `events`/`errors`, is removed: those modules now get the real one.
   `internal/errors` loads inspect lazily (the real inspect requires
   `internal/errors`). `internal/host/{util,buffer,encoding}` are loader-provided
   modules (the floor, `globalThis.Buffer`, `TextEncoder`/`TextDecoder`).
5. **`console` formats with it.** `scripts/node-console.js`, evaluated after the
   loader, replaces the shim's console methods under `--node`. Calls whose
   arguments are all strings or primitives (and whose first string has no `%`) are
   formatted inline; anything else loads the `util` builtin on first use, so a
   script that only prints strings pays nothing. The shim's own console stays for
   its documented no-host fallback (`scripts/run-node-shim-selftest.sh`).
   `console.dir` passes `customInspect: false` like Node. `Buffer`'s
   `inspect.custom` (`<Buffer 61, tag: 'x'>`) is `internal/buffer_inspect`,
   installed on `Buffer.prototype` by the loader (the shim's old
   `Buffer.prototype.inspect` is replaced).
6. **`util.js` adaptations.** `getCallSites` parses `Error().stack`;
   `parseEnv` is a JS port of Node's dotenv parser; `_errnoException` and
   `_exceptionWithHostPort` are plain `Error`s with the same fields;
   `getSystemErrorName/Map/Message` read a table generated from Node on Linux
   (`internal/util/uv_errmap.js`, 85 entries); `convertProcessSignalToExitCode`
   reads the Linux signal table; `setTraceSigInt` validates and does nothing (no
   SIGINT watchdog thread); `TextEncoder`/`TextDecoder` are the prelude's globals;
   `transferableAbortController/Signal` are added to `internal/abort_controller`.
   `internal/util`, `internal/errors` and `internal/validators` gain the pieces
   above (deprecate, promisify, `isError`, `removeColors`, `defineLazyProperties`,
   `validateOneOf/Array/StringArray/BooleanArray/Union`, the MIME/parse-args/
   assertion error codes).

## Divergences from Node

- **Error stacks.** The engine has no `Error.captureStackTrace` and gives errors
  no `stack`, so `inspect(new Error("x"))` prints the stackless form
  `[Error: x]` that Node uses for an error whose stack has no frames. Errors with
  an assigned `stack` print exactly as in Node. `getCallSites()` returns `[]`.
  `showHidden` on an error or on a sloppy function differs because the engine
  models `stack`, `caller` and `arguments` as own properties differently.
- `getStringWidth` is Node's non-ICU table (Node with ICU asks ICU), which only
  moves the column grouping of arrays containing unusual wide characters.
- `getConstructorName` for an object whose prototype chain names no constructor
  uses the engine's class name, not V8's map constructor.
- `util.styleText` accepts any stream-like object by duck typing instead of
  Node's stream classes; `isExternal`, `isKeyObject` and `isCryptoKey` are false.
- `parseArgs()` without `args` under `-e` reads `process.argv.slice(2)` (the
  engine does not tell the prelude it was started with `-e`).
- `util.getSystemErrorMap()` is the Linux table on every host.
- `inspect` recognises WHATWG `URL` objects through `globalThis.URL` (#1230).

## Verification

`scripts/run-node-util-oracle.sh` runs `scripts/util-fixtures/corpus-*.js` on jsse
`--node` and on Node, diffs stdout and stderr byte for byte, and checks the final
digest against `corpus.digest`: `util.inspect` under every option on primitives,
strings, arrays, typed arrays, buffers, objects, classes, getters, functions,
errors (fixed stacks), dates, RegExps, collections, iterators, weak collections,
promises, proxies, custom inspectors and 250 seeded random value trees; `format`
and `formatWithOptions`; `util.types` for ~100 values; `promisify`,
`callbackify`, `inherits`, `deprecate`, `isDeepStrictEqual` (~60 pairs),
`parseArgs`, `styleText`, `MIMEType`, `parseEnv`, `debuglog` and the system error
tables. `tests/node_util.rs` pins the digest (plain and `--no-bytecode`, and under
`JSSE_GC_STRESS`), the absence of the floor without `--node`, the console output
for buffers and typed arrays, and proxy/promise/iterator introspection without
running user code. The three events max-listeners-warning fixtures that waited on
`util.inspect` (`needs-inspect`) run unconditionally now.
