# Node host mode: the os module

Status: accepted (#1222), epic #1214. Extends `2026-10-26-0854-node-host-mode.md`.

**`os`** (#1222). `node-lib/os.js` is Node v26.8.2 `lib/os.js` (MIT) over a
private binding instead of `internalBinding('os')`. The binding is one hidden
floor global, `__host_os` (`node_host_os.rs`, `node_host_os_sys.rs`,
`node_host_os_constants.rs`), shaped like Node's: lists are flat primitive
arrays (`getCPUs`, `getInterfaceAddresses` in 7-tuples), and a failing call
fills its `ctx` argument (`errno`/`code`/`message`/`syscall`) and returns
`undefined`, which `os.js` raises as `ERR_SYSTEM_ERROR`. The loader captures
the object, deletes the global and seeds it as the private module
`internal/host/os` (with the prelude's `Buffer` for
`userInfo({ encoding: 'buffer' })`); only builtins can `require` it. Rules:
- The OS environment is never read natively: `homedir()` is
  `process.env.HOME` (`USERPROFILE` on win32) when set, even if empty, as
  `uv_os_homedir` does, and falls back to the passwd entry; `tmpdir()` is
  `TMPDIR`, `TMP`, `TEMP`, `/tmp`, minus one trailing `/`.
- `platform()`, `arch()`, `EOL` and `devNull` come from the binding
  (`std::env::consts` mapped to Node's names: `macos` to `darwin`, `windows`
  to `win32`, `x86_64` to `x64`, `aarch64` to `arm64`, ...), not from
  `process.platform`/`process.arch`, which the prelude still hard-codes
  (#1314). The win32 and darwin branches are covered by in-crate tests that
  override the platform name.
- Linux data is read from `/proc` (`meminfo`, `uptime`, `stat`, `cpuinfo`)
  and sysfs, like libuv; the rest uses `libc` (`uname`, `gethostname`,
  `getpwuid_r`, `getifaddrs`, `get/setpriority`, `getloadavg`), a
  unix-only dependency. `os.constants.signals`/`errno`/`dlopen` come from
  `libc` constants in Node's key order. Gaps: other unixes report no
  memory, uptime or cpus; macOS has no MAC addresses; Windows has no native
  queries beyond the platform, and only a signals table.
- Verification: `scripts/run-node-os-oracle.sh` diffs
  `scripts/os-fixtures/probe.js` against Node under ten environments (HOME
  and TMPDIR variants, in-script `process.env` edits); `tests/node_os.rs`
  and the unit tests in `node_host_os*.rs` need no Node.
